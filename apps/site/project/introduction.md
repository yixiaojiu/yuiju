# 项目介绍

yuiju 是一个由 LLM 驱动的虚拟角色自主生活模拟项目。

它不以问答和任务执行为中心，而是尝试让角色在一个持续推进的虚拟世界中拥有自己的日常。角色会感知时间、天气、地点和自身状态，决定接下来要做什么，并把实际发生的行为沉淀为经历、记忆、日记和计划。

> 不做 AI 智能助手，做有自己生活的“人”。

你可以通过 [https://yuiju-web.yixiaojiu.top](https://yuiju-web.yixiaojiu.top/) 体验当前正在运行的虚拟世界。

## 不只是聊天机器人

普通聊天机器人通常在用户发来消息后才开始生成回答。yuiju 的角色即使没有收到消息，也会继续生活：上学、散步、吃饭、购物、工作或休息。

QQ、飞书和 Web 是用户观察与介入这段生活的窗口。角色的回复、近况和主动分享会结合真实的世界状态、行为历史与对话上下文，而不是每次临时生成一段互不关联的人设文本。

## 角色如何生活

角色生活由持续运行的世界模拟引擎推进，核心流程可以概括为：

```text
读取世界与角色状态
        ↓
筛选当前可执行的 Action
        ↓
由 LLM 在候选行为中做出决定
        ↓
执行 Action 并更新实时状态
        ↓
记录行为与经历，进入下一轮生活
```

LLM 负责在明确的候选范围内决策，不直接修改角色状态。每个 Action 都定义自己的前置条件、执行副作用和持续时间，因此一次选择最终会落实为可验证、可记录的世界变化。

## 核心概念

### Character 与 World

Character 表示角色的实时状态，例如所在地点、体力、饱腹、心情、金币、背包和当前行为。World 表示角色所处环境的事实，例如时间与天气。

Redis 是这些实时状态的真相源。世界状态会影响角色能做什么，角色执行的 Action 也可能反过来改变状态。

### Scene 与 Action

Scene 是角色可以生活的具体场景，例如家、学校、商店、咖啡馆、公园、神社和海岸。

Action 是角色行为的最小执行单元。系统先根据场景和当前状态筛选可执行 Action，再让 LLM 做选择。这样既保留角色决策的开放性，也让每次行为的结果与耗时保持明确。

### Plan、MemoryEpisode 与 Diary

Plan 表示角色的长期或短期计划，让生活不只围绕眼前的一轮决策展开。

MemoryEpisode 保存已经发生的经历事实，是可追溯的历史记录。Diary 基于经历生成叙事归档，但不会替代 Episode 记录的事实。MongoDB 用于保存行为历史、记忆、日记和消息等长期记录。

### Message

Message 是角色与外部用户交互的入口。消息系统通过 Satori 接入 OneBot 和飞书，把不同平台的消息转为统一结构，再结合对话历史、角色状态与记忆生成回复。

当生活中发生值得分享的事情时，世界引擎也可以通过消息服务向指定群聊主动发送近况。

## 项目组成

项目使用 pnpm workspace 组织多个包：

| 模块              | 职责                                                          |
| ----------------- | ------------------------------------------------------------- |
| `@yuiju/world`    | 推进世界状态与角色行为，执行 Action，生成经历、计划和主动分享 |
| `@yuiju/message`  | 接入 QQ、飞书等消息平台，维护会话上下文并发送回复             |
| `@yuiju/dashboard` | 新版管理界面，展示角色、世界状态、活动、记忆和日志             |
| `@yuiju/utils`    | 提供配置、数据存储、LLM、记忆、提示词和公共类型               |
| `@yuiju/source`   | 保存角色图片、数据集和辅助脚本等资源                          |
| `packages/python` | 提供按需启动的 Graphiti 长期记忆图谱能力                      |

旧 Web 已删除，由 `apps/dashboard` 替代；上表中的 World、Message、Utils 为保留的旧模块。

## 运行时结构

一次完整部署主要包含三个应用进程和两项基础设施：

| 组件            | 作用                                     |
| --------------- | ---------------------------------------- |
| `yuiju-world`   | 持续推进角色生活                         |
| `yuiju-message` | 接收和发送外部消息，同时提供内部消息 API |
| Dashboard       | 提供新版 Web 页面与查询接口               |
| Redis           | 保存角色与世界的实时状态                 |
| MongoDB         | 保存行为、消息、记忆和日记等历史记录     |

LLM Provider 为行为选择、对话、总结、日记和视觉理解等流程提供模型能力。旧模块的业务配置来自项目根目录的 `yuiju.config.json`；Dashboard 使用新系统的 `data/config/config.json`，读取新系统产生的数据。

## 当前边界

yuiju 仍处于早期开发阶段。当前项目围绕一个具体角色和她的世界持续演进，不是通用 Agent 平台，也不提供一套开箱即用的多角色创建系统。

# 历史资料归档

本目录保存历史方案、调研笔记、临时 TODO 和未落地设计。

归档内容不能直接作为当前实现事实引用。需要使用时，先对照当前代码、`docs/README.md` 中的活跃文档和对应包 README，确认其中的说法是否仍然成立。

## 目录

- `spec/`：历史技术方案和阶段实现计划。
- `notes/`：调研笔记、想法草稿和问题记录。
- `todo.md`：早期临时 TODO。

## 维护规则

- 新的开发约定应写入活跃文档或规则文档，不写入 archive。
- 新的临时调研如果没有落地为当前事实，可以放入 archive，并在文件开头写明背景。
- 从 archive 迁出内容时，需要重写为当前事实描述，而不是原样复制。

# 项目开发计划 (Plan)

## 短期目标 (Q2 2026)
- [ ] **好感度系统**：实现基于互动的动态好感度计算与持久化。
- [ ] **Action 模块增强**：
  - [ ] 增加更多生活化动作（如：种菜、钓鱼、做饭）。
  - [ ] 优化动作执行的参数校验。
- [ ] **世界观扩展**：
  - [ ] 新增地点：后山（包含基础的战斗/采集逻辑）。
  - [ ] 完善天气系统对角色行为的影响。

## 中期目标
- [ ] **多端联动**：优化 Web 界面与消息服务的同步延迟。
- [ ] **物品系统**：实现基础的背包与商店售卖机制。
- [ ] **睡眠与觉醒**：实现更真实的作息时间循环与叫醒机制。

## 长期目标
- [ ] **角色间互动**：支持多个 Agent 之间的自主对话与社交逻辑。
- [ ] **环境演变**：世界状态会根据角色的集体行为产生长期影响。

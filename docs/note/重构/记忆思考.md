记忆是 "重建", 不是 "读取"
人每次回忆，都是拿当前的情绪、认知、需要，把碎片重新拼一遍, 所以同一件事今天和明年想起来不一样，还会记错、脑补。
→ 启发：检索时不要把 belief / 日记原文直接塞进 context, 而是取碎片 + 用她 "此刻的状态" 重新叙述一遍。这样回忆天然带主观色彩、会随心情变形 —— 这正是 "活" 的感觉，而且顺便解决了记忆读起来像档案的问题。
检索是 "线索触发", 不是 "关键词查询"
人很少主动搜索记忆，大多是环境线索勾出来的: 闻到味道、下雨、走到某条街，记忆自己冒出来。
→ 启发：你已经有天气 / 地点 / 时间。让当前世界状态本身当检索 query—— 她走进厨房→自动激活 "做饭相关记忆", 下雨→勾出 "上次下雨的事"。这让主动分享有了自然的触发源，而不是定时器硬推。
联想扩散激活
想起一件事会顺带激活相连的事，一个勾一个。
→ 启发：命中一条记忆时，顺着 evidence / 同一人物 / 同一天，带出 1-2 条相邻记忆。这靠 SQL JOIN 就能做，不需要图，却能让她的联想有 "跳跃感" 而非孤立回答。
情绪一致性检索
人心情差时更容易想起糟糕的事，好心情勾出好回忆。
→ 启发：检索打分里把她当前情绪当一个权重, 和记忆的 valence 做匹配。同一个问题，她开心时和低落时回忆起的往事不同 —— 情绪状态直接塑造她记得什么。
叙事自我：身份是一个 "故事", 不是一堆标签
人不是靠一列偏好定义自己，而是靠一个能自洽的人生叙事("我是个 XX 样的人") 在组织记忆，新经历要么融进故事、要么被叙事忽略。
→ 启发：在 belief 之上再加一层极小的 "自我叙事"(几段话：我是谁、我在意什么、最近在经历什么)。它由日记定期提炼，又反过来当过滤器决定什么经历值得记。这是让角色有 "连贯人格" 而不是 "一致数据" 的关键。
遗忘是功能，不是 bug
人脑主动删细节、只留要义 (gist), 才不会被淹没。记不清细节但记得 "大概" 和 "感受"。

---

一个人不是靠 "属性清单" 存在的，而是靠一个 "能自圆其说的故事" 存在的。

标签式的自我是这样的：身高、职业、喜欢咖啡、性格内向…… 它是一组静态属性，可穷举、无时间、无因果。但你会发现，没有人真的这样理解自己。你理解 "我是谁", 靠的是一条有起因、有转折、有走向的时间线: 我从哪来、经历了什么、那些事怎么把我变成现在的我、我要去哪。属性是故事的沉淀物, 不是本体 —— 你喜欢咖啡，背后是 "大学熬夜那段日子" 这个情节；标签只是故事磨掉细节后剩下的壳。

选择性。 故事不收录一切。你一生几万天，真正进入 "我的故事" 的只有几十个节点。什么被选进来，本身就在定义你是谁—— 同样的经历，有人讲成 "我克服了", 有人讲成 "我被毁了", 于是成了不同的人。记忆不是被动记录，是主动编剧。
重述性。 同一件往事，20 岁和 40 岁讲法不同。不是记错了，是当下的你在用现在的意义重新解释过去。故事一直在被改写，而人还是同一个人 —— 因为连续的不是内容，是那个 "一直在讲" 的动作本身。
意义高于事实。 自传体记忆常常细节失真，但 "那件事对我意味着什么" 高度稳定。人可以记错时间地点，却极少搞错 "那是我人生的转折"。故事的真，是意义的真，不是档案的真。
面向未来。 标签只描述过去和现在，故事却有走向 ——"我正在成为一个 XX 样的人"。身份里天然含着尚未发生的章节, 这就是为什么目标和计划是身份的一部分，而不是外挂。

双时间尺度，把 "情绪" 和 "人格" 分开。
短期 (每天): 情绪、状态可以由 LLM 自由波动，高温、鲜活，允许她今天开心明天低落。这层随便变，不影响身份。
长期 (母题 /belief): 只在 "睡眠固化 / 每周复盘" 这种低频、聚合多天证据的环节才可能动，而且不是重写，是微调。突变被挡在这一层外面。

你的直觉 "action 少 → 变量少 → 连续性会僵"——这个因果其实不成立, 而且它误判了故事的来源。真实的人生也高度重复：上班、吃饭、睡觉，一辈子没几种 action, 但没人觉得自己的人生是复读。因为变化不来自 "发生了什么", 而来自 "同一件事对此刻的我意味着什么"。 四个撬动点:

让 action 的 "意义" 依赖内在状态，而非 action 本身。
同一个 "散步", 在她 {心情低落 / 刚和你吵完 / 母题正处于转变期 / 这是本月第一次放晴} 下，是四段完全不同的经历。5 个 action × 情绪 × 天气 × 关系状态 × 第几次 是组合爆炸—— 你缺的从来不是 action 种类，是让这些维度去给 action 上色。世界薄没关系，内在厚就够了。
重复本身要能 "积分" 成东西。
她第 100 次做饭必须和第 1 次不同 —— 因为她记得前 99 次。重复要沉淀成熟练、厌倦、仪式感、或 "这是我和你的固定节目"。让重复变成角色发展的燃料，而不是枯燥的证据。 这恰恰需要你的记忆系统在场。
加一个 "戏剧节奏引擎", 别追求每天都有事。
平淡的日常是底噪, 是真实的，不用怕。你要的是拍点: 当系统检测到她 "太久没有波澜"(情绪平、母题没进展), 就注入一个低频扰动—— 生病、考试、一个新角色出现、一次小意外。故事 = 平淡打底 + 偶发转折。你不需要每周很多事，你需要偶尔一件对的事。
让 "长期计划 / 目标" 给重复的日子一个方向。
即使每天都在重复，只要她朝一个目标在推进(攒钱买样东西、学会一件事、修复一段关系), 日子就因为 "在朝某处去" 而不再原地打转。方向性是连续性最便宜的解药, 而你已经有计划模块了。
你真正要建的不是 "更多 action", 而是一层厚的内在状态(情绪、关系、母题进度、计划), 它一头吸收慢速证据来防突变, 一头给稀疏的 action 染色来防僵化。世界可以一直很薄，只要这层内在够厚，少量 action 就能长出无穷的、连续的、缓慢演变的故事。
世界模块的 action 数量先别扩，那是投入产出最低的方向。先把 "内在状态 → 给经历赋义" 这条链做厚, 你会发现现有的几个 action 已经够她过出一辈子了。要我把这层 "内在状态" 具体拆成哪几个变量、各自怎么更新、怎么接进现有的日记 / 固化流程吗？

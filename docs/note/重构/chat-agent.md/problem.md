# 聊天 agent 测评记录

## 问题

| 问题               | 实际表现                                                                       |
| ------------------ | ------------------------------------------------------------------------------ |
| Replyer 扩写事实   | Planner 只交代“贝壳收在家里”，Replyer 补成“放在书桌旁边”，有时还编颜色、盒子。 |
| 把未知当作确定近况 | 只知道喜欢轻小说、不知道近期书目，却说“最近没在追”或“最近随便翻翻”。           |
| 聊天凭空推进生活   | 前一句“想泡柠檬水”，后一句“已经泡好了”，期间没有世界活动反馈。                 |
| 关心容易套路化     | 经常附带休息、吃点喜欢的、注意防晒等建议；连续看像照顾人的助理。               |
| 人设表达有表演感   | 反复害羞、停顿、日语敬称、反问，偶尔把纠正理解成亲近的打闹。                   |
| 输出波动明显       | 同一场景一次克制、下一次又编细节，单次好结果不能证明修复。                     |
